Cara kerja QA Web Recorder

Suite

Kumpulan skenario test untuk satu halaman/fitur. Contoh: suite "Login" berisi semua skenario terkait login.

Scenario

Satu alur/cerita test di dalam suite. Contoh: "Admin berhasil login" adalah satu scenario.

Step

Satu aksi yang direkam di dalam scenario — klik, ketik, scroll, dan seterusnya.

Mengekspor semua suite tersimpan ke satu bundel .json. Mengimpor sebuah bundel akan menambahkan suite-nya ke library kamu — tidak pernah menggantikan atau menghapus yang sudah ada.

Menggabungkan semua suite tersimpan menjadi satu project Cypress: satu file spec per suite, dengan Page Object bersama saat dua suite menyentuh halaman yang sama. Siap disalin atau diekspor sebagai satu repo.
